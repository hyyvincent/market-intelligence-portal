# 中国乘用车企业财报与资本市场看板

本地静态 HTML 看板，仅保留两个模块：最新业绩与财报关键指标、股市综合看板。

## 使用

在本目录启动本地静态服务器后打开 `index.html`。页面打开时会尝试同步腾讯证券覆盖的最近行情；其他市场跳转官方投资者关系页面。

## 数据口径

- 覆盖中国本土乘用车集团、中国新势力，以及在华合资车企的海外母公司。
- 财报采用实际上市/披露主体的集团口径，不把合资公司销量替代为集团财务数据。
- 未上市或暂未完成当期核验的企业保留在持续监控区，不使用估算值补齐。
- 财报表现已覆盖并显示全部 29 家企业；未独立披露或仅按季披露收入的主体在对应字段明确标注，不放到表外隐藏。
- 表格数值采用简写，鼠标悬浮可查看“归母净利润、经营现金流、调整后口径”等完整定义。
- 不同会计准则、币种、利润定义和现金流口径不直接汇总。
- 当前核验截止日：2026-07-29。
